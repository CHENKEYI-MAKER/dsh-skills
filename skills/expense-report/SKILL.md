# 填写与提交报销单

> ⚠️ 这是**样板技能**，用来示范格式与粒度。里面的部门、限额、邮箱都是占位值，
> 推广前必须由财务部逐条核对替换。

## 什么时候做这件事

员工因公发生了要公司付钱的支出，事后要拿回这笔钱，或者要把发票交给财务入账。

**不适用**：向公司预支现金（走借款单）、给供应商付款（走付款审批）、差旅标准咨询（属于制度问答，不要写进本技能）。

## 需要先确认的信息

| 信息 | 从哪拿 | 拿不到怎么办 |
| --- | --- | --- |
| 费用类型 | 问用户：差旅 / 采购 / 招待 | 无法归类时先停，不要猜 |
| 金额 | 发票或支付凭证 | 金额缺失必须追问，不能留空 |
| 发生日期 | 发票日期 | 与支付日期不一致时以发票为准并备注 |
| 审批人 | 直属上级 | 不确定时交给财务指定 |

## 步骤

1. **分桶归类**：把每笔费用归到差旅 / 采购 / 招待之一。一笔一张行，不要合并同类模糊项。
2. **核对票据**：逐张检查发票抬头、税号、金额是否齐全。缺抬头的票据先退回补开，收进来也过不了账。
3. **填模板**：复制 `templates/expense.xlsx` 为新文件，命名 `报销-<姓名>-<YYYYMM>-<序号>.xlsx`。
4. **算总额**：模板里的合计是公式，不要手写数字覆盖它。
5. **写说明**：每笔在"事由"列写清楚，例如"10/12 拜访温州客户往返高铁"。
6. **提交**：把填好的表 + 票据照片发给财务邮箱，并@直属上级确认。

## 判断分支

| 情况 | 怎么做 |
| --- | --- |
| 单笔超过 [限额] 元 | 必须附上级书面同意（聊天记录截图也算） |
| 招待费 | 额外写明被招待方单位与人数 |
| 跨月费用 | 在事由里标注实际发生月，避免计入错误月份 |
| 发票抬头不是本公司 | 退回补开，不要收 |

## 常见错误

- ❌ 把多笔费用合并成一行 → ✅ 一笔一行，否则财务无法拆分核对
- ❌ 手改合计单元格 → ✅ 只填明细，合计用公式
- ❌ 票据先斩后奏、月底一次性补 → ✅ 发生后一周内提交

## 完成后检查

- [ ] 每笔费用都有对应票据
- [ ] 发票抬头、税号、金额三项齐全且与明细一致
- [ ] 合计由公式得出，未被手写覆盖
- [ ] 超过限额的已附上级同意
- [ ] 文件名符合 `报销-<姓名>-<YYYYMM>-<序号>.xlsx`
