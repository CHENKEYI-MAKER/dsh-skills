# 填写与提交报销单

> ⚠️ 这是**样板技能**，用来示范格式与粒度。里面的部门、限额、邮箱都是占位值，
> 推广前必须由财务部逐条核对替换。

## 触发条件

- 员工因公发生了要公司付钱的支出，事后要拿回这笔钱，或者要把发票交给财务入账时加载本技能
- 用户会这么说：「我要报销」「帮我填报销单」「这几张票怎么报」「10 月出差花了 X 元」
- **不适用**：
  - 向公司预支现金 → 走借款单
  - 给供应商付款 → 走付款审批
  - 问差旅标准（住宿能不能报 500）→ 属于制度问答，直接答，不要走本流程

## 步骤

1. **归类费用**
   - 输入：用户口述或票据照片
   - 做什么：把每笔费用归到**差旅 / 采购 / 招待**之一。归类拿不准时**先停下来问**，不要猜
   - 产出：一份"笔数 × 类型"的清单
2. **核对票据**
   - 输入：发票照片或 PDF
   - 做什么：逐张检查**抬头、税号、金额**三项是否齐全且与明细一致
   - 产出：可入账的票据清单 + 需要补开的票据清单（缺抬头的先退回补开，收进来也过不了账）
3. **填模板**
   - 输入：`templates/expense.xlsx`
   - 做什么：复制为新文件，命名 `报销-<姓名>-<YYYYMM>-<序号>.xlsx`；一笔一行，逐行填入
   - 产出：填好的报销表
4. **算合计**
   - 做什么：模板里的合计单元格是**公式**，不要手写数字覆盖它
   - 产出：由公式得出的总额
5. **写事由**
   - 做什么：每笔在"事由"列写清具体事由，例如"10/12 拜访温州客户往返高铁"
   - 产出：财务看得懂的语义化明细
6. **提交**
   - 做什么：把表 + 票据照片发给财务邮箱，并 @ 直属上级确认
   - 产出：已提交的凭证（邮件/消息记录）

**判断分支**

| 情况 | 怎么做 |
| --- | --- |
| 单笔超过 [限额] 元 | 必须附上级书面同意（聊天记录截图也算） |
| 招待费 | 额外写明被招待方单位与人数 |
| 跨月费用 | 在事由里标注实际发生月，避免计入错误月份 |
| 发票抬头不是本公司 | 退回补开，**不要收** |

## 坑

- ❌ 把多笔费用合并成一行 → ✅ 一笔一行（原因：财务无法拆分核对）
- ❌ 手改合计单元格 → ✅ 只填明细，合计用公式
- ❌ 票据先斩后奏、月底一次性补 → ✅ 发生后一周内提交
- ⚠️ 金额接近或超过限额时必须**先读** `references/limits.md`，那里写了限额和需要的附件；不读会漏掉审批附件，整单被退

## 验收标准

- [ ] 每笔费用都有对应票据
- [ ] 发票抬头、税号、金额三项齐全且与明细一致
- [ ] 合计由公式得出，未被手写覆盖
- [ ] 超过限额的已附上级同意
- [ ] 文件名符合 `报销-<姓名>-<YYYYMM>-<序号>.xlsx`
- [ ] 已提交给财务并 @ 了直属上级

## 参考文件
