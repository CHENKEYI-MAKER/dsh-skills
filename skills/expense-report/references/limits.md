# 费用限额与所需附件（占位值，待财务核对）

> 本文件是**按需加载**的参考资料：`SKILL.md` 正文里只在"接近或超过限额"时让 AI 读它。
> 这就是为什么要拆出来 —— 绝大多数报销根本用不到这张表，不该每次都占上下文。

| 费用类型 | 单笔限额（元） | 超过限额需要的附件 |
| --- | --- | --- |
| 市内交通 | 100 | — |
| 城际高铁（二等座） | 无上限，实报实销 | 行程单 |
| 住宿（一线城市） | 500 / 晚 | 水单 |
| 住宿（其他城市） | 350 / 晚 | 水单 |
| 招待费 | 300 / 人 | 上级书面同意 + 被招待方名单 |
| 办公用品采购 | 1000 | 采购申请单 |

## 需要额外审批的情形

- 单笔超过上表限额：直属上级书面同意
- 单月招待费累计超过 3000 元：分管副总同意
- 跨年度补报：财务负责人同意

## 不接受的票据

- 抬头非本公司、或税号错误
- 只有收据没有发票（除小额定额发票）
- 与"事由"描述不符的品名
